# compositors bind XF86MonBrightnessUp/Down to that wrapper, so on a machine with
# a panel those two keys are dead without it. On a desktop there is no
# /sys/class/backlight to write to and the package is pure weight -- which is
# exactly the state this repository was in: declared as required, not installed,
# and nobody noticing because the machine has no backlight to miss.
