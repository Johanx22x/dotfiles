# The applications and command-line tools the tracked configuration is written
# against.
#
# Required rather than optional because files in this repo name them: ranger's
# scope.sh calls atool, highlight, mediainfo and ffmpegthumbnailer; the
# launcher and the screenshot binds call grim, slurp, satty, hyprshot and
# hyprpicker; zsh's config calls eza, bat, fd, fzf, zoxide and starship. A
# machine that skips this list gets a desktop whose keybinds point at commands
# that are not there.
#
# stow is the one entry that is about the installer itself: it is what links
# every other directory in this repo into $HOME.
#
# WHAT LEFT THIS LIST, AND THE LINE THAT SENT IT AWAY. btop, openrgb and
# i2c-tools were here and nothing in this repository calls any of the three.
# Two of them even have a tracked config -- shell/.config/btop/btop.conf and
# openrgb/.config/OpenRGB/OpenRGB.json -- and that is the distinction worth
# writing down, because it is the one that got them filed wrong: a file in
# here that CONFIGURES a program is not a file in here that DEPENDS on one.
# Take btop off a machine and its config sits unread; take satty off one and
# SUPER+SHIFT+S is a keybind pointing at nothing. Only the second kind earns
# a place on this list. The three are in optional/apps.txt and
# optional/hardware.txt now.
