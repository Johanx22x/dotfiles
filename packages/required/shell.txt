# The desktop this repository is: Quickshell, the wallpaper daemons, the colour
# generator and the fonts they all assume.
#
# "shell" is the Quickshell session -- bar, island, launcher, notifications,
# settings window -- and not the login shell, which lives in desktop.txt with
# the rest of the terminal.
#
# awww and mpvpaper are one feature between them: a still or an animated GIF
# goes through awww, a video wallpaper through mpvpaper, and wallpaper-switch
# picks by extension. matugen is what turns the image into the accent palette
# every other file here reads.
#
# wl-gammarelay-rs is the niri half of the blue light filter and is listed here
# rather than in compositor/niri.txt because it is harmless under Hyprland,
# where hyprsunset owns the gamma and nothing starts this one.
#
# yay is in this list rather than being bootstrapped by hand: a good half of
# what is above comes from the AUR, and the installer builds yay from source
# only when the name cannot be resolved any other way.
#
# THE BROWSER USED TO BE HERE AND IT WAS WRONG TWICE OVER. zen-browser-bin
# sat in this file, which is the Quickshell session and the fonts it assumes
# -- a browser is not part of that under any reading -- and it was required,
# which it is not. What this repository has for Zen is a theme and nothing
# else: the matugen template that writes ~/.zen/rice/chrome/colors.css, the
# userChrome.css that zen/ links into the profile, and desktop-opacity's Zen
# block. All three write files that Zen reads; none of them is something Zen
# makes work. It is in optional/apps.txt now, next to brave-bin.
